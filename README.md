# NeuralTrack #
## I promise this is actually useful its not just generative AI to replace the artist I swear ##
This program is made to assist VFX artists in a process that's usually a pain. The main inspiration for this tool is CorridorKey which is a greenscreen tool that uses neural networks to get an ALMOST perfect greenscreen :D
### So you have told me the inspiration BUT WHAT DOES THIS ACTUALLY DO ###
In VFX to make the rendered objects integrated with the video you have to do something called Camera Tracking..... THIS PROCESS (in my experience) SUCKS.
It fails a lot, it can be inaccurate or the one that I get the most, IT JUST HATES YOUR FOOTAGE. So I had a thought one time. "If corridor key works by using a neural network, trained on CGI renders where the neural network will guess the result, and then due to the greenscreen images being CGI it can be given the correct image. Why can't I just do the same thing with CameraTracking.", That was the thought process so here's how it should work (if this project ends up working lol)
## "how it should work (if this project ends up working lol)" ##
I will make a CGI video of a camera moving inside a somewhat complex scene,
Then i will make the neural network guess the positions of camera, It will probably be wrong on the first time, So I give it the actual camera movement, Which I can just DO because its CGI. Geez that was a long sentence that was probably plagued with grammar issues.
